## 🔌 Умный дом и датчики

### 1. OAuth per-user (подключение умного дома пользователя)
**Статус:** ⏳ запланировано

Сейчас токен Яндекс Умного Дома один на всех (`YANDEX_IOT_TOKEN` в env). Нужно, чтобы **каждый пользователь подключал свой Яндекс** и сервер читал его устройства.

- Таблица `user_oauth_tokens (user_id, provider, access_token, refresh_token, expires_at)` — токены **шифровать**.
- Флоу: пользователь в приложении жмёт «Подключить Яндекс» → `oauth.yandex.ru/authorize` → сохраняем токен → сервер читает его устройства через `api.iot.yandex.net/v1.0/user/info`.
- Scope: `iot:view` + `iot:control` (достаточно для чтения датчиков).
- Сложность: **высокая** (шифрование токенов, флоу, безопасность).

### 2. Уведомление Яндекса / требования для публичного приложения
**Статус:** ⏳ запланировано

Проверить требования Яндекса для **публичного** OAuth-приложения (сейчас личное). Для раздачи токенов многим пользователям Яндекс обычно требует модерацию приложения на `oauth.yandex.ru` и может ограничивать выдачу токенов.

- Проверить раздел про модерацию и лимиты на `oauth.yandex.ru`.
- Решить: начинать с малого (пара тестовых аккаунтов) или сразу публиковать.
- **Не выдумывать условия** — верифицировать на официальной странице.

### 3. История температуры балкона + средняя день/ночь + шторка на 3 дня
**Статус:** ⏳ запланировано

Сейчас `GET /balcony/status` отдаёт только **текущую** температуру. Нужна история, чтобы пользователь сам решал, выставлять ли растение.

- Таблица `balcony_temp_readings (user_id, temp_c, read_at)` — балконный монитор пишет показания каждые 30 мин.
- Средняя дневная/ночная = агрегат по времени суток.
- Шторка «последние 3 дня» = выборка из истории.
- Сложность: **средняя**.

## 🔐 Политика конфиденциальности

### 4. Обновить политику под сбор данных датчиков + OAuth + Telegram
**Статус:** ⏳ запланировано

Добавить в политику:
- **Какие данные собираем**: показания датчиков (влажность, температура, влажность воздуха, заряд батареи) из подключённого умного дома.
- **Как получаем**: через OAuth-подключение к Яндекс Умному Дому + Telegram (если бот).
- **Зачем**: показ ухода за растениями, алерты, балконный мониторинг.
- **Хранение и срок**: история показаний, сколько храним, где, шифрование токенов.
- **Третьи лица**: Яндекс (OAuth + чтение устройств), Telegram (бот).
- **Согласие**: поле `personal_data_consent_at` — явное согласие на подключение умного дома.

Файл: `docs/architecture/privacy.md` + `docs/privacy.html` (публичная страница).
